# 대화 서버

대화 서버는 휴대폰 앱과 웹 데모가 실제로 붙는 서버예요. 여러 사람이 한 대화방에
들어오면 받아쓰기는 방마다 한 번, 번역은 언어마다 한 번만 해서 모두에게 나눠
줘요. 클라이언트와는 WebSocket으로 이야기해요. <!-- S02-C001-01 -->

::: info WebSocket이 뭔가요 웹 주소처럼 생긴 연결(`ws://…`)을 한 번 열어 두고,
양쪽이 계속 메시지를 주고받는 방식이에요. 휴대폰은 마이크 소리를 계속 보내고,
서버는 받아쓴 글과 번역을 계속 돌려줘요. :::

## 대화방(conversation)

클라이언트가 처음에 같은 대화방 ID(`conversationId`)를 보내면 같은 방에
들어가요. <!-- S02-C001-01 -->

```
 화자 A (소리 보냄, 한국어로 받음) ─┐
 화자 B (소리 보냄, 영어로 받음)  ─┼→ 대화방 ─ 받아쓰기 1번 ─┬→ 한국어 번역 1번 → A, C
 청자 C (소리 안 보냄, 한국어)    ─┘                         └→ 영어 번역 1번   → B
```

- **받아쓰기는 방마다 한 번이에요.** 소리를 보내는 클라이언트마다 채널이 되고,
  채널을 하나로 섞어서 받아써요.
- **번역은 목표 언어마다 한 번이에요.** 같은 언어를 원하는 사람은 같은 결과를
  받아요.
- 소리를 보내지 않는 클라이언트는 **청자**예요. 같은 받아쓰기와 번역을 받아요.

<!-- S02-C001-01 -->

## 서버 하나는 모델 하나예요

영어용과 한국어용 받아쓰기 모델은 서로 다른 파이프라인이에요. 서버 하나는 그중
하나만 들고, 사용자는 말할 언어에 맞는 서버에 붙어요.

## 아직 없는 것

- 대화방을 만들고 지우는 HTTP API가 없어요. 누군가 들어와 있는 동안만 방이
  있어요.
- 입장 권한 확인이 없어요. 방 ID를 아는 사람은 누구나 들어올 수 있어요.
- 늦게 들어온 사람은 들어온 뒤의 결과만 받아요. 지난 내용은 받지 못해요.
- 클라이언트 하나는 번역 언어 하나만 받아요.
