# bench

bench는 파이프라인을 녹음 파일에 돌려 점수를 매기는 프로그램이에요. 파이프라인
설정 하나와 데이터셋 설정 하나를 이름으로 골라 합치면 실행 하나가 돼요. 실행이
끝나면 결과 폴더와 점수가 남고, 팀 S3에 올라가요.

<!-- S01-C001-01 S01-C001-32 -->

## 서버 없이 같은 부품을 돌려요

bench는 [대화 서버](../server/)를 띄우지 않아요. 받아쓰기, 커밋 규칙, 번역 같은
부품은 서버와 똑같아요. 다만 한 프로그램 안에서 직접 조립해요.

녹음은 실제 말하는 속도 그대로 흘려 넣어요. 그래서 지연 시간 점수도 실제 상황과
같은 시계로 재요. <!-- S01-C001-02 S01-C001-23 -->

```
데이터셋 설정 (무엇을 먹이나)  ─┐
                               ├→  bench  →  bench/runs/<데이터셋>/<파이프라인>/
파이프라인 설정 (무엇을 재나)  ─┘               summary.json (점수 요약)
                                                items.jsonl, events.jsonl …
```

<!-- S01-C001-01 S01-C001-26 -->

## 어떻게 돌리나요

| 방법                       | 언제                                      | 문서                                        |
| -------------------------- | ----------------------------------------- | ------------------------------------------- |
| 실험 매니저의 Queue에 넣기 | **기본**. GPU 머신이 시간표에 맞춰 돌려요 | [Queue — 실험 넣기](../bench-manager/queue) |
| 이 컴퓨터에서 `make bench` | 설정을 빨리 시험하거나 GPU를 혼자 쓸 때   | [이 컴퓨터에서 돌리기](./run-locally)       |

<!-- S01-C001-03 S01-C001-06 -->

직접 돌려도 결과는 똑같이 S3에 올라가요. 그래도 Queue를 먼저 써요. 직접 돌린
실행은 그 머신의 시간표와 대기열을 거치지 않아서 같은 GPU를 쓰는 다른 job과
부딪칠 수 있어요. <!-- S01-C001-06 -->
