# 소음, 울림, 긴 발표

데이터셋 설정에 몇 줄을 더하면 같은 녹음을 다른 조건으로 잴 수 있어요.
`augment`는 깨끗한 녹음에 장소 소음과 공간의 울림을 입혀요. `longform`은 문장을
하나씩 흘리지 않고 발표나 대화 전체를 한 번에 흘려요. 원본 데이터는 건드리지
않아요. <!-- S01-C001-22 S01-C001-21 -->

## 소음과 울림 입히기 (`augment`)

카페 소음을 입힌 실제 설정이에요. <!-- S11-C001-03 -->

```yaml
meta:
  description:
    FLEURS Korean sentences with cafe noise (DEMAND SCAFE, level 0.1-0.5); quiet
    clips raised to -23 dB
  tags: [fleurs, sentence, noise]
dataset:
  name: fleurs/ko_kr
target: en
augment:
  noise:
    place: cafe
    level: [0.1, 0.5] # 소음 크기 ÷ 말소리 크기. 0.5면 소음이 말의 절반 크기
  volume:
    min_level_db: -23 # 이보다 작은 녹음만 여기까지 키워요
```

효과는 세 가지이고, 이 순서로 입혀요. <!-- S01-C001-22 -->

| 효과     | 하는 일                           | `level`의 뜻                                                        |
| -------- | --------------------------------- | ------------------------------------------------------------------- |
| `room`   | 공간의 울림을 입혀요 (예: `hall`) | 울린 소리의 몫. 0이면 원음 그대로, 1이면 전부 울린 소리             |
| `noise`  | 장소 소음을 섞어요 (예: `cafe`)   | 소음 크기 ÷ 말소리 크기                                             |
| `volume` | 너무 작은 녹음을 키워요           | `min_level_db`: 최소 소리 크기(dBFS). 말소리는 보통 −26 ~ −20이에요 |

<!-- S01-C001-22 -->

- **설정 하나에 장소는 하나예요.** 장소를 섞으면 점수가 떨어져도 어느 장소
  탓인지 가릴 수 없어요.
- **숫자는 범위 `[낮음, 높음]`이에요.** 항목마다 그 안에서 골라요.
  `level: 0.3`처럼 하나만 쓰면 `[0.3, 0.3]`이에요.
- **무작위지만 항목마다 늘 같아요.** 같은 설정으로 다시 돌리면 같은 소리가 나요.
- **소음 버전은 파일을 따로 둬요.** `fleurs_ko-en_cafe.yml`처럼 이름을 달리해야
  깨끗한 실행을 덮어쓰지 않아요.

<!-- S01-C001-22 -->

### 소음 파일은 어디에 있나요

데이터 루트의 `augment/` 아래에 장소 이름으로 된 폴더에 있어요. 폴더 안의
`.wav`가 모두 후보이고 항목마다 하나를 골라요. 없는 장소를 적으면 있는 장소
목록을 알려 주고 멈춰요. <!-- S01-C001-22 -->

```
$STITY_DATA_ROOT/augment/
  noise/<장소>/*.wav    # 예: cafe, station, traffic
  room/<장소>/*.wav     # 공간의 울림 (예: hall, church, office)
```

[Replay](../bench-manager/replay)에서는 소음을 입힌 소리 그대로 들려요.

## 발표 전체를 흘리기 (`longform`) {#longform}

```yaml
dataset:
  name: fleurs/ko_kr+en_us
  longform: true
```

기본은 문장을 하나씩 따로 흘려요. `longform: true`이면 같은 발표(`group`)의
문장들을 묶어 **그 오디오 파일을 처음부터 끝까지** 한 번에 흘려요. 실제 발표나
대화처럼 문장 사이가 이어지는 상황을 재요. <!-- S01-C001-21 -->

이때 몇몇 점수가 바뀌어요. <!-- S01-C001-21 -->

| 점수                | 바뀌는 것                                        |
| ------------------- | ------------------------------------------------ |
| `longyaal_ms`       | 새로 나와요. 발표 단위의 번역 지연이에요         |
| `laal`, `yaal`      | 빠져요. 발표 전체를 문장 하나로 보면 뜻이 없어요 |
| `bleu`, `comet`     | 결과를 정답 문장 단위로 다시 나눈 뒤 매겨요      |
| `wer`, `cer`, `fsl` | 발표 전체에서 그대로 나와요                      |

일부만 돌리려면 `limit: N`을 써요. 이때 N은 발표 개수예요. 이 경우도 설정 파일을
따로 둬요. <!-- S01-C001-21 S01-C001-20 -->
