# 용어 정리

문서 전체에서 이 이름들만 써요. 모르는 말이 나오면 여기로 돌아와요.

## 실험의 단위

| 용어 | 뜻 |
|---|---|
| 파이프라인 설정 | *무엇을 재는지* 적은 YAML 파일이에요. 어떤 ASR 모델, 어떤 번역 모델을 쓸지 적어요. `configs/pipelines/<이름>.yml` |
| 데이터셋 설정 | *무엇을 먹이는지* 적은 YAML 파일이에요. 어떤 녹음 묶음을 어느 언어로 번역할지 적어요. `configs/datasets/<이름>.yml` |
| 실행(run) | 파이프라인 설정 하나와 데이터셋 설정 하나를 합쳐 한 번 돌린 것이에요. 결과 폴더 하나가 생겨요 |
| 항목(item) | 데이터셋 안의 녹음 하나예요. 보통 문장 하나예요 |
| 데이터셋 | 녹음 파일과 정답 문장을 모아 둔 폴더예요. 별도 저장소(`datasets`)에 있어요 |
| job | 실험 매니저의 대기열에 넣은 실행 하나예요. GPU 머신이 차례로 꺼내 돌려요 |

## 파이프라인 안의 부품

| 용어 | 뜻 |
|---|---|
| ASR | Automatic Speech Recognition(자동 음성 인식). 말소리를 글자로 받아써요 |
| MT | Machine Translation(기계 번역). 받아쓴 글을 다른 언어로 옮겨요 |
| VAD | Voice Activity Detection(음성 구간 검출). 말이 시작하고 끝난 곳을 찾아요 |
| 커밋(commit) | "이 문장은 끝났다"고 확정하는 순간이에요. 커밋된 문장만 번역해요. git의 커밋과는 다른 말이에요 |
| partial | 아직 확정되지 않은 받아쓰기예요. 말하는 동안 화면에 흐리게 보여요 |
| final | 커밋되어 번역까지 붙은 결과예요 |

## 장비와 저장소

| 용어 | 뜻 |
|---|---|
| GPU | 모델을 돌리는 그래픽 카드예요. 실험은 GPU 머신에서 돌아요 |
| VRAM | GPU에 달린 메모리예요. 모델이 여기에 올라가요 |
| S3 | 팀이 함께 쓰는 Amazon 클라우드 저장소예요. 설정 원본과 실행 결과가 여기 있어요 |
| worker | GPU 머신마다 하나씩 도는 프로그램이에요. 대기열에서 job을 꺼내 돌려요 |
| 시간표 | worker가 job을 시작해도 되는 요일과 시간이에요 |
| uv | 파이썬 프로그램과 그 라이브러리를 설치하고 실행하는 도구예요 |
| `make` | 긴 명령을 짧은 이름으로 부르는 도구예요. `make bench`처럼 써요 |

## git과 소리

| 용어 | 뜻 |
|---|---|
| 브랜치 | git에서 작업을 나눠 두는 갈래예요. 보통 `main`을 써요 |
| push | 내 컴퓨터의 커밋을 GitHub(`origin`)에 올리는 일이에요. GPU 머신은 GitHub에 올라간 코드만 봐요 |
| 코퍼스 | 공개된 녹음 모음이에요. FLEURS가 그 예예요 |
| dBFS | 소리 크기 단위예요. 0이 가장 크고, 말소리는 보통 −26 ~ −20이에요 |
| vLLM | 번역 모델 같은 큰 언어 모델을 GPU에서 빠르게 돌리는 프로그램이에요 |

## 점수(지표) {#metrics}

화살표는 좋은 방향이에요. ↓는 낮을수록, ↑는 높을수록 좋아요.

| 지표 | 무엇을 재나요 | 단위 |
|---|---|---|
| WER ↓ | 받아쓰기에서 틀린 단어의 비율 | 0~1 (0.1이면 10%) |
| CER ↓ | 받아쓰기에서 틀린 글자의 비율. 한국어는 띄어쓰기를 무시해요 | 0~1 |
| BLEU ↑ | 번역이 정답 번역과 얼마나 겹치는지 | 0~100 |
| COMET ↑ | 번역 품질을 모델로 매긴 점수 | 0~1 |
| FSL ↓ | 커밋이 그때까지 들어온 소리보다 얼마나 늦게 나왔는지 | 초 |
| LAAL, YAAL ↓ | 번역이 말보다 평균 얼마나 늦었는지 | 밀리초(ms) 또는 초 |
| Token emission ↓ | 단어를 말한 뒤 그 단어가 화면에 바뀌지 않고 남기까지 걸린 시간 | 초 |
