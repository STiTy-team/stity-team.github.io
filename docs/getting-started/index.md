# 시작하기

STiTy 실험 도구는 세 가지예요. 모델 성능을 재는 **bench**, 그 실험을 웹에서 넣고 비교하는 **실험 매니저**, 그리고 실제 앱이 붙는 **대화 서버**예요. 이 섹션은 셋 모두에 필요한 준비를 다뤄요. <!-- S12-C001-01 S01-C001-03 S02-C001-01 -->

## STiTy가 하는 일

STiTy는 말소리를 받아 실시간으로 받아쓰고 다른 언어로 번역해요. 소리는 아래 순서로 흘러가요. <!-- S12-C001-01 -->

```
마이크 소리
  → VAD (말이 시작되고 끝난 곳 찾기)
  → ASR (받아쓰기)
  → 커밋 (문장이 끝났다고 확정하기)
  → 번역
  → 휴대폰이나 웹 화면
```

이 순서 전체를 **파이프라인**이라고 불러요. 처음 보는 말은 [용어 정리](./terms)에 모아 두었어요.

## 도구 세 개가 맡는 일

| 도구 | 하는 일 | 언제 쓰나요 |
|---|---|---|
| [실험 매니저](../bench-manager/) | 웹사이트에서 실험을 GPU 머신에 넣고, 결과를 비교하고, 다시 재생해요 | 실험을 돌리고 결과를 볼 때. 가장 자주 써요 |
| [bench](../bench/) | 파이프라인을 녹음 파일에 돌려 점수를 매겨요 | 설정 파일을 만들거나, 이 컴퓨터에서 직접 돌릴 때 |
| [대화 서버](../server/) | 휴대폰 앱과 웹 데모가 붙는 실제 서버예요 | 앱으로 시연하거나 서버를 고칠 때 |

<!-- S01-C001-03 S01-C001-02 S02-C001-01 -->

bench는 서버를 띄우지 않아요. 서버와 같은 부품을 한 프로그램 안에서 조립해서 녹음 파일을 흘려 넣어요. 그래서 서버 없이도 점수를 잴 수 있어요. <!-- S01-C001-02 -->

## 읽는 순서

1. [용어 정리](./terms): 문서에 나오는 말을 먼저 훑어요.
2. [설치하기](./install): 필요한 프로그램과 저장소를 받아요.
3. [.env 설정하기](./env): 이 컴퓨터만의 설정 파일을 만들어요.
4. [원격 서버에서 쓰기](./remote): GPU 서버에 접속해서 쓸 때 읽어요.
5. 그다음 하려는 일에 맞춰 [실험 매니저](../bench-manager/), [bench](../bench/), [대화 서버](../server/)로 가요.

::: tip 처음이라면
실험을 돌려 보기만 할 거라면 1~4를 마치고 [실험 매니저](../bench-manager/)로 바로 가요. 코드를 고치지 않아도 실험을 넣을 수 있어요.
:::
